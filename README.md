# タイプトレーナー Web

ブラウザで動くタイピング練習ソフトです。インストール不要で、`index.html` 1ファイルだけで動きます。

## 練習メニュー

1. ポジション練習（ホームポジション／上一段／下一段／数字／全段 など8種類）
2. ランダム練習
3. 英単語練習（基本英単語・プログラミング用語）
4. ローマ字練習（ランダム・単語）
5. 成績表示（最高入力速度・達成日・累積練習時間）
6. 成績消去

## 主な特徴

- **単語の間のスペースは打たなくてOK**：単語を打ち終えると自動で次の単語に進みます。
- **単語の途中で改行しない**：行末で単語が2行に分かれないので読みやすくなりました。
- 今打っている単語を黄色で表示し、常に上から2行目に来るよう自動スクロールします。
- ローマ字は色々な打ち方に対応（`si`/`shi`、`tu`/`tsu`、`n`/`nn`、`kka`/`ltu` など）。
- 次に押すキーと使う指を、画面下のキーボードで表示します。
- 成績はブラウザ（localStorage）に保存されます。
- ダークモード・スマホ画面に対応（練習にはパソコンのキーボードが必要です）。

## 操作方法

| 画面 | キー |
| --- | --- |
| メニュー | 番号キー、または ↑↓ + Enter |
| 練習中 | 表示された文字を入力。Esc でメニューへ |
| 練習終了後 | Enter でもう一度、Esc でメニューへ |

※ 日本語入力（IME）はオフ（半角英数）にして練習してください。

## GitHub Pages で公開する手順

1. GitHub にログインし、右上の「+」→「New repository」でリポジトリを作成（例：`typetrainer`、Public）。
2. 「Add file」→「Upload files」で `index.html` と `README.md` をアップロードし、「Commit changes」。
3. リポジトリの「Settings」→ 左メニュー「Pages」を開く。
4. 「Build and deployment」の Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして「Save」。
5. 1〜2分後、`https://ユーザー名.github.io/typetrainer/` で公開されます。

## カスタマイズ

`index.html` 内の `<script>` の先頭付近を編集します。

- 制限時間：`const LIMIT = 60;`
- 練習する単語：`JA_WORDS`（ひらがな）、`EN_WORDS`、`PROG_WORDS` にスペース区切りで追加
